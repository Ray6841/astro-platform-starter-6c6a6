# Zen Skin & Beauty – Static Site Refresh

A lightweight, elegant static website redesign for Zen Skin & Beauty.

## Preview locally

```bash
cd /workspace/zen-skin-site
python3 -m http.server 8080
# open http://localhost:8080
```

## What’s included

- Accessible, responsive layout with refined typography and color system
- Key sections: Hero, Services, Featured CACI, HC Clinic, Gallery, Location, Contact
- SEO meta, Open Graph, and LocalBusiness JSON‑LD
- Click‑to‑call and booking CTAs wired to existing numbers/links

## Deploy

- Any static host (Netlify, Vercel, GitHub Pages, S3/CloudFront)
- Upload the contents of this folder as your site root

## Content to update

- Replace external Unsplash/gallery images with your own hi‑res assets
- Update pricing PDF link when you publish the latest price list
- Add social media links (header/footer) if required
